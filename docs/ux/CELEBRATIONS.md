# Celebrations

Still has none, on purpose.

Breathing slowly is not an achievement to reward, and a reward would turn a calm moment into a score. So there is no confetti, no badge, no streak and no sound of victory.

| Moment | What happens | Why it is not a celebration |
|---|---|---|
| End of a session | "That's it.", the minutes breathed today, one soft haptic and, if sounds are on, one chime | A quiet close, the same every time, never louder for a longer session |

Rules if this ever changes: at most one per session, only for something real and rare, never when the app opens and never at random.
