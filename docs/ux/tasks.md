# Core tasks

The three core tasks, counted in taps from launch. Each must take 3 taps or fewer. Replay this list before every release and update the counts.

| Task | Taps | Path |
|---|---|---|
| Breathe to calm down | 1 to 2 | Home, (Calm card if another mode is selected), Begin |
| Breathe to fall asleep | 2 | Home, Sleep card, Begin |
| Read a verse and breathe | 3 | Home, Trust card, Begin, Breathe |

Secondary tasks:

| Task | Taps | Path |
|---|---|---|
| Stop a session | 2 (or Back) | Tap the screen, Stop |
| Turn sounds and haptics off | 3 | Settings, then the Sound and Haptics switches |
| Export sessions | 3 or fewer | Settings, Export my sessions |
| Erase everything | 3 or fewer, plus typing ERASE | Settings, Erase everything, Erase |
