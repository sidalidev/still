# Security review, 31 Oct 2026

Internal review of the design of Still 0.1.0, written while the first version is being built. No external audit.

## Scope

The planned app at 0.1.0: manifest and permissions, stored data (`Store.kt`), the breathing engine (`Engine.kt`), haptics and sound (`Haptics.kt`, `Sound.kt`), verses (`Verses.kt`), About, build configuration and CI. Grid: OWASP MASVS-L1 for storage, network, platform interaction and code quality.

## Findings

**Network.** No INTERNET permission. No dependency may add one: CI checks the merged release manifest against `docs/permissions.txt` and fails if INTERNET appears. Sounds and verses ship inside the APK, so nothing is ever fetched.

**Permissions.** `VIBRATE`, for the breath haptics (`VibrationEffect.Composition`, with a waveform fallback). `DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION` is added by AndroidX to protect its own receivers and grants nothing. No microphone, no location, no notifications, no wake lock, no foreground service.

**Storage.** One small JSON file in the app's private storage, holding finished sessions only: start time, mode, minutes. Settings (sound, haptics, ambience, session lengths) live in private `SharedPreferences`. No database, no logs, no identifiers. Other apps cannot read either without root. Export opens the system file picker (`ACTION_CREATE_DOCUMENT`) and writes one JSON file, `still-sessions.json`, only where the user chooses, off the main thread; Erase everything deletes the sessions file and the settings at once, after the user types ERASE.

**Backups.** App data is excluded from cloud backups and device-to-device transfers (`allowBackup=false` and `dataExtractionRules`), so sessions never leave the phone that way either. Export is the only way out, and the user starts it.

**Sleep mode.** The screen stays on but black (`FLAG_KEEP_SCREEN_ON` on the window), with no background service and no wake lock. The session ends on its own and the window flag is cleared, so the phone can sleep normally.

**Sound.** Sounds play only when the ringer mode is normal; silent and vibrate are respected. Taps go through the view (`performHapticFeedback`), so the system touch feedback setting applies. The breath textures are played by the `Vibrator` with the media usage, so the system media vibration setting applies, and they stop when the in-app Haptics switch is off or the view has haptic feedback turned off.

**Exported components.** `MainActivity` (launcher) only. The About activity is not exported.

**Code.** Kotlin and AndroidX only. No native code of our own: the only `.so` is `libandroidx.graphics.path`, shipped by AndroidX Compose (aligned to 16 KB pages). No third-party SDK, no analytics.

**Signing.** One release key, kept outside the repository. Its certificate SHA-256 will be published in `SECURITY.md` with the first release and is shown in About from the installed APK.
